# Netlify static edition

This folder is a browser-only portfolio edition of the EGFR Streamlit project.

## What it does
- Loads the existing mutation-held-out prediction CSV and model-comparison CSV directly from the GitHub repository.
- Lets visitors select an EGFR mutation and compare experimental with held-out predicted TKI responses.
- Shows model-comparison and validation summaries.
- Requires no Python server, so there is no Streamlit process to sleep.

## Important difference from app.py
The Python Streamlit app can load the final CatBoost `.cbm` model. A static Netlify site cannot execute that Python model directly. This edition therefore emphasizes the precomputed mutation-held-out predictions, which are the appropriate validation predictions already generated by the modeling pipeline.

## Add to the repository
Copy this entire `web` folder into the repository root. Also add `netlify.toml` at the repository root.

Then in Netlify:
1. Import the GitHub repository.
2. Leave the build command blank.
3. Publish directory: `web`
4. Deploy.

The data URLs in `web/app.js` point to:
https://github.com/Evan-CRD/egfr-resistance-predictor
