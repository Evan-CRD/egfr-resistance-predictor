1 · Dataset

One row per mutation–drug pair, including EGFR mutation, published structure–function group, exon assignment, TKI, and relative drug response.

2 · Replicate response

The pipeline uses the median of available replicate measurements, reducing the influence of unusually high or low measurements.

3 · Candidate feature sets

Drug-only, drug + exon, drug + structure group, drug + structure + exon, and a mechanism-enhanced representation were compared using the same validation procedure.

4 · CatBoost regression

CatBoost boosted decision trees can directly use categorical labels and learn nonlinear interactions between drug identity and biological representation.

5 · Mutation-held-out validation

All rows for a mutation remain together. When that mutation is tested, none of its drug-response measurements are present in training.

What the model learns

Prediction target

The target is log₂(mutant IC50 / wild-type IC50). A value of 0 indicates similar IC50, +1 corresponds to approximately twofold higher mutant IC50, and −1 to approximately half the WT IC50.

Selected biological inputs

The project evaluates drug identity together with published EGFR structural and exon-based representations. The structural class is locked to the published mutation assignment to avoid unsupported mutation–class combinations.

Why held-out predictions?

They test generalization to mutations not seen during training rather than allowing the model to benefit from other measurements of the same mutation.

Limitations and responsible interpretation

This is an experimental relative-response model, not a clinical treatment recommendation.
  • The model uses published expert-defined structural labels; it does not infer structural class from a raw PDB structure.
  • Results are based on the source study and should not be interpreted as patient-specific treatment predictions.
  • This static portfolio edition displays precomputed mutation-held-out predictions. The Python repository contains the full modeling workflow.
